# 资源、文案与国际化规范

> 状态：生效 ｜ 责任人：FE ｜ 复核：M1 结束

## 1. 支持语言（v1.0）

| 语言 | locale | 状态 |
|---|---|---|
| 简体中文 | `zh` | 默认、完整 |
| 英文 | `en` | 完整 |

新增语言（P2）：日/韩先做 UI，不承诺台本识别模型。

## 2. 文案管理

- 唯一来源：`apps/app/lib/l10n/app_zh.arb`（模板）+ `app_en.arb`；
- 生成配置 `l10n.yaml`：`template-arb-file: app_zh.arb`、`output-localization-file: app_localizations.dart`、`nullable-getter: false`；
- 生成命令：`flutter gen-l10n`（CI 校验生成结果无 diff）；
- 代码引用：`AppLocalizations.of(context)!.readerPause`，禁止字符串拼接；
- **禁止**：UI 里写中文/英文字面量；原生层写用户可见文案；在 domain 层依赖 `BuildContext`。

### Key 命名

`<feature>.<component>.<action|label|hint>`

```
reader.control.pause
reader.control.speedUp
library.import.previewTitle
settings.permission.micDenied
error.permission.mic
```

- 同一含义只保留一个 key；不复用为不同语境（英文可能不同）；
- 文案带参数必须声明类型：`{count}` → `"count": {"type": "int"}`；
- 复数/选择用 ICU：`{count, plural, =0{无台本} other{{count} 个台本}}`；
- 中文标点用全角，英文用半角；不在 ARB 中写 HTML。

## 3. 硬编码检查

CI 执行：

```bash
dart run tool/check_hardcoded_strings.dart --exclude lib/l10n
```

规则：`Text('...')`、`tooltip: '...'`、`label: '...'` 中出现 CJK 或英文句子即失败；允许白名单（日志、测试、协议常量）。

## 4. 字体与排版资源

| 资源 | 位置 | 规则 |
|---|---|---|
| 阅读页中文字体（Heavy 900） | `apps/app/assets/fonts/SourceHanSansSC-Heavy.otf` | Source Han Sans SC Heavy / 同源 Noto Sans SC Black；SIL OFL 1.1；**不做子集裁剪**（2026-11-06 决策：体积只记录） |
| 许可证 | `apps/app/assets/licenses/SourceHanSansSC-OFL.txt` | 随包分发，OFL 要求保留版权与许可全文 |
| 字体声明 | `pubspec.yaml` `fonts:` | family 名 `SourceHanSansSC`，weight 900 |
| 字体令牌 | `design_system` `TpTokens.readerFontFamily` | 阅读页默认；编辑页/设置页保持 Material 默认字体 |
| 缺字回退 | 系统字体链 | 禁止出现方框；Golden 覆盖生僻字用例 |

- 字体来源、SHA256、资产大小与许可记录在 [DEPENDENCY_POLICY.md §7](../process/DEPENDENCY_POLICY.md) 与 `NOTICE`；
- 阅读页字号/行距/镜像/高亮不随字体切换改变（仅替换 family/weight），字体变更必须回归这四项；
- 用户导入字体（P2）需校验文件头、大小上限 30 MB、失败回退系统字体（内置字体本身不受该上限约束）；
- 用户台本内容不做翻译，语言仅影响 UI。

## 5. 数字、日期、时间

- 一律用 `intl` 的 `NumberFormat`/`DateFormat`，按 locale 格式化；
- 时间码（录制/SRT）用 `HH:mm:ss.SSS`，固定等宽数字；
- 文件大小用 IEC（KiB/MiB）还是 SI，统一按系统惯例：设置页用 MB（1 MB = 1024 KB），日志用字节；
- 中文日期 `2026-11-06`，不使用"11月6日"以外的歧义格式。

## 6. 无障碍文案

- 图标按钮必须提供 `tooltip` 与 `semanticLabel`，两者可复用同一 key；
- 图片/装饰 `ExcludeSemantics`；
- 朗读摘要（阅读态"当前位置"）单独 key，限长 60 字，节流 ≥ 1 s；
- 错误文案必须包含"发生了什么 + 下一步怎么做"，例：
  - 中文：`未获得麦克风权限，已切换为匀速滚动。可在系统设置中开启后重试。`
  - 英文：`Microphone access is off. Switched to constant scrolling. Enable it in System Settings to use voice follow.`

## 7. 资源目录与命名

```
assets/
├── fonts/
├── models/          # 不提交 Git，按 models.lock.json 获取
├── images/          # 仅 UI 插画，2x/3x 同目录
└── licenses/        # 第三方与字体许可全文
```

- 图片：`snake_case`，按用途命名（`empty_library.png`），禁止 `img1.png`；
- 所有第三方资源必须在 `NOTICE` / `assets/licenses/` 有对应许可；
- 模型资源见计划文档 §15.4.4：不入 Git、构建期校验 SHA256。

## 8. 新增文案流程

1. 先在 `app_zh.arb` 加 key 与中文；
2. 同 PR 补 `app_en.arb`；
3. `flutter gen-l10n`；
4. 若涉及权限/错误，必须同步 `docs/permissions.md` 或错误码表；
5. 评审检查：无硬编码、key 命名合规、占位符类型正确。
