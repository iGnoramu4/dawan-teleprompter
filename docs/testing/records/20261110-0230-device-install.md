## 3. 语音跟随首次准备（含模型解包）

状态栏文案依次为「安装离线模型…」→「加载识别器…」→「跟读中（麦克风）」；解包期间无百分比进度，只有文案。

| 场景 | 实测（点麦克风 → 跟读中） |
|---|---:|
| 中英混合首次（解包 208,661,419 B） | **10.7 s** |
| 中文轻量首次（解包 25.4 MB） | **3.5 s** |
| 中英混合再次（已解包，仅加载） | 4.3 s |
| 中文轻量再次（已解包，仅加载） | 5.9 / 6.3 s |

- 解包为一次性：`files/asr_models/<id>/.installed-v1` 命中后不再写盘。
- 失败回滚：**未验证**（本次未构造写盘失败场景；代码路径是循环内抛错即中断 `_prepare`，状态回落到错误提示，未经实测确认）。
- 轮询粒度为 1 s，上述时间含 ≤1 s 采样误差；「已解包」两组差异在误差内，不作为模型快慢结论。

## 4. 产品口径 PSS（TOTAL PSS）

采样时机：每次先 `am force-stop` 再冷启动，进入目标状态后 **等待 60 s 稳定**，连续 3 次、间隔 8 s 取值。

| 状态 | 样本（KB） | 中位（KB / MB） |
|---|---|---:|
| 空闲首页（启动后 20 s，无识别） | 275,752 / 273,648 / 273,435 | 273,648 KB ≈ **267.2 MB** |
| 中文轻量跟读稳定 60 s | 480,784 / 465,444 / 466,615 | 466,615 KB ≈ **455.7 MB** |
| 中英混合跟读稳定 60 s | 665,876 / 662,473 / 663,150 | 663,150 KB ≈ **647.6 MB** |

- **中英混合相对中文轻量：+196,535 KB ≈ +191.9 MB**（中位对中位；样本区间差 181.7–200.4 MB）。
- 首次安装、未做 force-stop 的首页样本为 272,281 / 278,018 / 277,962 KB，与上表一致。
- 对照提醒：harness（`tool/eval_device`，无页面渲染）同口径差值为 +162.8 MB；产品态多出的是图形与 Dart/原生堆，两者不可直接混用。同一进程内先跑混合再切 14M 会因原生堆不回落（曾出现 320 MB Native Heap）而失真，故本次每个状态都独立冷进程。

## 5. 语音跟随真实麦克风

| 项 | 结论 | 证据 |
|---|---|---|
| 默认混合模型加载 | **实测通过** | 首启 10.7 s 后状态为「跟读中（麦克风）」 |
| 出识别 | **实测通过（一次性观测）** | 混合运行中出现「识别：重点了想谈三个问题」，与台本首行一致 |
| 推动锚点 | **未验证** | 全程停留 `1 / 5`，没有连续朗读输入，无法判定是否按句推进 |
| 首字时间 | **未验证** | 需真人按稿朗读并从拍手/起音对时，本次无受控语音源 |
| 卡行 | **未观察到（但样本不足）** | 无推进即无卡行可观测；14M 出现噪声误识别「行了我今天应该别太多了」时，锚点仍在 `1 / 5`，未误跳行 |

> 结论只覆盖「加载 + 短时出词」。30 分钟真实环境音的命中率、误触发、首字与跟随延迟仍待补测。

### 用户自测步骤（30 分钟真实环境音）

1. 打开「语音跟随演示」（或自建台本），点麦克风，等状态变「跟读中（麦克风）」。
2. 按台本连续朗读 ≥30 分钟，中途故意停顿 3–5 次、跳读 1–2 行、插入一段即兴。
3. 结束时从设置导出诊断包，记录：命中率（推进是否跟手）、误触发次数、明显卡行位置、首字观感延迟。
4. 想对比轻量模型：设置 → 识别模型 → 中文轻量，**下一次**开始语音跟随时生效，重复第 1–3 步。

## 6. 切回中文轻量路径

| 项 | 结论 | 证据 |
|---|---|---|
| 设置可切换 | **实测通过** | 设置 → 识别模型 → 中文轻量，说明文案即时变为「仅中文、占用更小…」 |
| 下次开始时生效 | **实测通过** | 切换后不打断当前会话；停止再开始，准备耗时与 PSS 变为 14M 量级 |
| 持久化 | **实测通过** | force-stop 后重启，设置面板仍显示所选模型；测试结束已切回默认「中英混合」 |
| 确实换了模型目录 | **仅间接证据** | 14M 与混合首次准备分别为 3.5 s / 10.7 s（对应 25 MB / 209 MB 解包），运行 PSS 差 191.9 MB；release 包不可 `run-as`、`/data/user/0` 无 shell 权限，**目录级直接证据取不到** |
