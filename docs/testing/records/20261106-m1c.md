# M1-c 测试记录（0.3.1+2004）

## 1. 环境

| 平台 | 设备 | 系统 | 构建号 | 模型档 |
|---|---|---|---|---|
| Android（模拟器） | sdk_gphone64_arm64（1080×1920） | Android 16 / SDK 36 | release，versionName 0.3.1，versionCode 2004 | zipformer-zh-14M-int8（asset 内置） |

- 构建：`flutter build apk --release`，产物 `apps/app/build/app/outputs/flutter-apk/app-release.apk`（163.4 MB）。
- 安装：`adb install -r`，覆盖旧版 0.3.0+2003，数据保留。
- 日志获取：生产包不可 `run-as`，统一走设置页「导出诊断包」（SAF 保存到 Download 后 `adb pull`）。
- 说明：版本号使用 `0.3.1+2004` 而非文档公式（0.3.1→301），避免 versionCode 降级导致安装失败；1.0.0 起切回公式。

### M1B-V1 补充：权限与麦克风

- 首次点“语音跟随”弹出系统录音权限；选“不允许”后应用提示“启动语音跟随失败：麦克风权限未授予”，无崩溃。
- `pm grant RECORD_AUDIO` 后再次启动：状态“跟读中（麦克风）”，ASR `ready`（loadMs 367–396 ms），置信度 0%，无识别更新（模拟器无麦克风音源）。
- 真机验证步骤（待补）：
  1. 安装 `app-release.apk`（0.3.1+2004），授予麦克风权限；
  2. 打开“语音跟随演示”，点“语音跟随”，按台本朗读；
  3. 观察状态置信度（应 > 0%）与高亮行推进；
  4. 导出诊断包，确认出现 `follow_update`（line 递增、confidence > 0、degraded 多为 false）；
  5. 记录设备型号/系统/构建号与首字延迟。

### M1B-V2 补充：锁定态证据

- 锁定（长按）后控制面板隐藏，仅保留“已锁定 · 点击解锁”徽标。
- 回放测试音频（`assets/test_wavs/demo_zh.wav`，5.15 s）期间锁定：
  - 锁定后第 1 帧：高亮第 1 段；
  - 2.5 s 后：正文上移，高亮第 2 段，徽标仍为锁定。
- 诊断包时间线：锁定后仍有 `follow_update`（line 2、confidence 0.17/0.63 等），证明语音链路未因锁定暂停。

## 3. 指标

| 指标 | 基线 | 实测 | 结论 |
|---|---|---|---|
| 跟随/滚动帧耗时（234 行，10 行/秒，release） | p95 ≤ 33.3 ms；janky 低 | frames 3656，avgBuild 0.89 ms，p95Build 2.63 ms，avgRaster 14.6 ms，p95Raster 20.57 ms，p95Total 23.88 ms，janky 35（0.96%） | 达标（模拟器） |
| 同上（14 行示例，10 行/秒，两次） | 同上 | p95Total 24.53/27.71 ms，janky 21/959（2.2%）、56/1690（3.3%） | 达标（模拟器，含页面转场） |
| 模型加载 | < 1 s（常驻） | loadMs 348–396 ms | 达标 |
| 跟随态帧率 | ≥ 55 fps（低端 ≥ 45） | 由 60 Hz vsync 与 p95Total 推算约 58–59 fps（模拟器） | 有条件达标，需真机复核 |
| 包体 | Android 单 ABI ≤ 120 MB | 通用 release APK 163.4 MB（含模型/assets，未拆 ABI） | 不达标项，待 M2 做 ABI 拆分后复测 |

滚动速率说明：帧耗时按设定 10 行/秒推进；前台进度按“逻辑行”计数，长英文句在 88 px 字号下会折成 2–3 个视觉行，故 13.5 s 时逻辑进度 60/234 对应视觉约 10 行/秒，与设定一致。

## 6. 结论

**有条件通过。**

- M1-c 三项（编辑→提词链路、全局默认参数页、JSONL 日志与诊断导出）实测通过，隐私约束在设备日志上复核通过。
- 锁定态语音跟随实测可继续推进；长台本 10 行/秒滚动在模拟器 release 包上 janky 0.96%、p95 23.88 ms。
- 真实麦克风输入跟随仅完成权限与接入验证，需按 §2 真机步骤补测后方可判定通过。
- 包体基线未达标（未拆 ABI），归入后续里程碑。
