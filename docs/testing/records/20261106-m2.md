## 12. 阅读页体验四项（0.10.0+2012）

设备：`emulator-5554`（Android 16 / SDK 36，1080×1920 @420dpi，逻辑宽 411.4）。固定竖屏、release APK。

### 12.1 左右边距：复现与根因

- 复现：`horizontalMargin` 从 6% 调到 12%，`settings_changed` 日志与面板数值都变化，但正文左右边界不动；把字号/每行字数改动后，换行结果与显示宽度仍然对不上。
- 根因：阅读页用 `OverflowBox` 只放开了高度（`maxHeight: infinity`），宽度沿用父级紧约束（全屏宽），内层 `SizedBox(width: _stageWidth)` 被强制撑满；而 `TextPainter` 按窄画布测量，于是「测量窄、渲染宽」，边距失效且换行/行高错位。
- 修复：`OverflowBox` 同时放开宽度（`minWidth: 0, maxWidth: infinity`），画布宽度统一取 `ReaderSettings.stageWidthFor()`（按边距收窄、封顶 980）。
- 回归：`test/reader_page_test.dart`「左右边距真实作用于渲染画布」断言逻辑宽 400、边距 12% 时 `SizedBox` 实际宽 304；`test/reader_settings_test.dart`「画布宽度按左右边距收窄并封顶 980」。

### 13.2 实现要点与踩坑

- **插件尺寸单位不一致**：`showOverlay` 的 `width/height/startPosition` 直接写入 `WindowManager.LayoutParams`（物理像素），而 `resizeOverlay/moveOverlay/getOverlayPosition` 使用 dp。首版按 dp 传入导致窗口只有约 140 dp 宽、内容只露出一行；已改为显示时 `dp × devicePixelRatio` 换算，位置仍按 dp 持久化。
- **关闭通道**：浮窗引擎只注册 `x-slayer/overlay`，`closeOverlay/getOverlayPosition` 在主引擎的 `x-slayer/overlay_channel` 上；因此 × 按钮经 `IsolateNameServer` 发 `close` 给阅读页，由阅读页读位置、落盘并关闭服务。
- **位置记忆**：`overlay:global` 预设保存 `widthDp/opacity/lineCount/fontSize/x/y`；关闭时读取 `getOverlayPosition()`（dp）。
- **权限声明**：`SYSTEM_ALERT_WINDOW`、`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_SPECIAL_USE`，并声明 `OverlayService`（`specialUse`、`exported=false`）。`POST_NOTIFICATIONS` 未声明，随后台跟随阶段补齐。

### 14.2 本轮修正记录
