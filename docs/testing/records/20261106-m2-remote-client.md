## 4. 未自动化 / 未验证

| 项 | 原因 | 替代验证 |
|---|---|---|
| 扫码配对 | `mobile_scanner` 不在本机 pub cache，本轮未引入依赖；遥控端改为粘贴配对串 | 用户可从主控端弹窗复制配对串；后续引入扫码时补集成测试 |
| 两台真实设备同网段连接 | 宿主测试只走回环，无法覆盖 AP 隔离、路由器防火墙、省电策略 | 真机/模拟器同网段手动回归 |
| 端到端延迟 < 100 ms（P95） | 需要两台设备与真实网络 | 同网段压测记录 |
| Android 后台/锁屏下 WebSocket 存活 | 需要设备前台服务与系统行为 | 真机后台回归 |
| 锁定态下遥控端与主控端状态一致性 | 单机 widget 测试只覆盖按钮禁用与 `state.locked` 展示 | 真机双端联调 |
| `scroll` 连续拖动、`jump` 分段跳转的实际手感 | 阅读页仅接入命令映射，缺少双端交互实测 | 真机联调 |
