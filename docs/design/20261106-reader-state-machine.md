# 阅读页状态机与逐行跟随（2026-11-06）

> 范围：提词页（`apps/app/lib/features/reader/reader_page.dart`）的起始态、逐行跟随、收音角标、画布宽度、语音匹配档位、段落化文本与功能栏显隐。
> 状态：生效 ｜ 维护：FE ｜ 更新：2026-11-10（`0.22.0+2025`，段落化文本 + 功能栏隐藏 + 开发音频入口）

## 1. 起始态（默认不自动滚动）

打开阅读页后进入 **idle**：不滚动、不推进锚点，控制面板保持可见并提示「轻点屏幕开始 · 语音跟随请点麦克风」。

| 触发 | 结果 |
|---|---|
| 轻点页面 / 点击播放按钮 | idle → running（手动滚动按台本速度） |
| 点击麦克风 | idle → running（语音跟随）；引擎加载期间角标显示「引擎加载中」 |
| 轻点页面（running 时） | running → paused（冻结滚动，锚点不动） |
| 轻点页面（paused 时） | paused → running |
| 读到篇尾（末行静止 0.6 s） | running → finished（暂停）；循环模式 1.2 s 后回到篇首并恢复 running |
| finished 时点播放 / 轻点页面 | finished → running（从篇首重新开始，等同循环复位） |
| 退出重进 / 切换台本 | 一律回到 idle（不恢复运行态，只恢复断点锚点） |
| 锁定 | 不改变 running/paused，仅屏蔽手势；语音跟随照常推进 |

约束：`paused` 或未开始时，语音识别结果只更新状态与置信度，**不移动锚点**。

## 2. 逐行跟随（默认开启，可切回平滑）

设置项 `lineStepFollow`（阅读设置 → 滚动）。判定由 `packages/core_alignment/lib/src/line_step_gate.dart` 实现，阈值来自当前语音匹配档位（见 §7，下表按**标准档**列出）：

| 条件 | 行为 |
|---|---|
| 候选行 ≤ 当前行 | 不推进（口误不回跳） |
| 候选 = 当前行 + 1，置信度 ≥ 0.55（final 额外 +0.15） | 立即切行 |
| 置信度 0.35–0.55 | 连续 2 次命中同一行或更远的行才切行 |
| 置信度 < 0.35 | 不推进；连续 3 次进入降级态（角标显示「低置信」） |
| 候选跳 > 3 行 | 单次最多前进 3 行并标记 leap（滚动层快速追赶），后续更新继续收敛 |
| 手动拖拽 / 跳段 / 重新开始 | 清空待确认状态，按新锚点继续 |

取舍：
- **逐行**：锚点只在切行时改变，行内不再随 partial 连续平移，消除「半行半行地飘」；代价是切行发生在识别确认后，单行内可能有 ~100–200 ms 的静默期。
- **平滑**（关闭开关）：保留原行为，每次识别都连续逼近跟踪行，适合跳读频繁或语速不稳的场景。
- 两种模式的滚动目标都是**视觉行行顶**：行顶最终对齐固定阅读带顶部，不会停在半行（§9）。

## 3. 收音状态角标（仅语音模式）

常驻在顶部阅读预留区（正文锚点落在固定阅读带内，带顶默认在安全区 34% 处，因此不覆盖当前行/高亮条），样式使用设计令牌（`StagePalette` + `TpTokens`），不接收触摸。

| 状态 | 判定 | 文案 |
|---|---|---|
| 后台 | 应用非 resumed | 后台收音 |
| 已暂停 | `paused` | 已暂停 |
| 引擎加载中 | 麦克风/模型未就绪 | 引擎加载中 |
| 低置信 | 跟踪器降级或最近置信度 < 0.35 | 低置信 |
| 静音 | 就绪且 2.5 s 无有效识别 | 未检测到语音 |
| 正在收音 | 其余情况 | 正在收音 |

优先级与实现见 `apps/app/lib/features/reader/mic_status.dart`（纯函数，可单测）。

## 4. 画布宽度（左右边距）

- 规则：`stageWidth = clamp(viewportWidth × (1 − 2 × horizontalMargin), 0, 980)`。
- 渲染与 `TextPainter` 测量必须使用同一个宽度；`OverflowBox` 需放开宽度约束（`minWidth: 0, maxWidth: infinity`），否则父级紧约束会把画布撑回全屏，导致边距失效且换行/行高与实际不一致。
- 回归测试：`apps/app/test/reader_page_test.dart`（渲染宽度）与 `reader_settings_test.dart`（公式/封顶）。

## 5. 悬浮窗镜像状态（W-03）

悬浮窗不持有独立业务状态，只镜像主阅读页（详见 [20261106-overlay-window.md](20261106-overlay-window.md) §4）：

- 主页面在 `started` / `paused` / `locked` / `voiceOn` / 收音角标变化时推送 `state`（签名去重）；
- 锚点变化每 200 ms 推送 `anchor`；
- 浮窗上的暂停、逐行、麦克风、锁定动作以 `control` 回到主页面执行，再回推 `state`，因此两条入口永远不会出现「浮窗已暂停、主页面仍在滚动」；
- 锁定是唯一的双向例外：锁定后浮窗只保留解锁操作，其余控制被主页面忽略。

## 6. 语音匹配档位（C-09）

设置项 `matchTolerance`（阅读设置 → 语音匹配宽松度），三档枚举 `MatchTolerance { strict, standard, loose }`，参数集中在 `packages/core_alignment/lib/src/match_tolerance.dart` 的 `MatchProfile`，一次驱动三处：

- `LineStepGate`（逐行推进闸门）：强命中、弱命中、final 加成、弱命中次数、单次最大前进行数；
- `AlignEngine`（对齐引擎）：滑窗前看行数 `lookAheadLines` 与预筛底线 `minScore`（= 档位弱命中阈值）；
- `AlignTracker`（锚点跟踪器）：普通候选接受底线 `acceptFloor` 与退出降级所需置信度 `recoverConfidence`。

| 参数 | 严格 strict | 标准 standard（默认，等价历史值） | 宽松 loose |
|---|---|---|---|
| 强命中立即切行 | ≥ 0.70 | ≥ 0.55 | ≥ 0.42 |
| 弱命中区间下限 | ≥ 0.45 | ≥ 0.35 | ≥ 0.22 |
| final 置信度加成 | +0.10 | +0.15 | +0.20 |
| 弱命中需连续次数 | 2 | 2 | 1 |
| 单次最多前进 | 2 行 | 3 行 | 4 行 |
| 滑窗前看行数 | 5 | 8 | 12 |
| 跟踪器接受底线 | 0.30 | 0.20 | 0.12 |
| 退出降级所需置信度 | 0.60 | 0.50 | 0.40 |

语义：

- **严格**：宁可漏跟也不抢行，适合安静环境、口播与稿件高度一致；对低置信候选更保守，恢复降级也更难。
- **标准**：默认档，与历史硬编码阈值完全一致（0.55 / 0.35–0.55 / +0.15 / 2 次 / 3 行 / 前看 8 行）。
- **宽松**：候选搜索更远、弱命中一次即推进、接受更低置信，适合噪声环境或即兴发挥较多；代价是更容易被近似口播带偏。

切换档位即时生效：闸门按 `LineStepGate.fromProfile` 重建，跟踪器用 `applyProfile` 热更新阈值并**保留当前锚点与平滑状态**，不会因为改档位而回跳或停麦。持久化字段 `matchTolerance` 写入台本预设与全局默认；未知或缺失值按 `MatchProfile.parse` 回落到标准档。

## 7. 每行字数与自动重排（已下线，2026-11-10）

- 正文改为**按空行分段、段内自然折行**后，不再需要按窗口宽度反推「每行字数」，也不再重建语义行：
  - 设置面板的「每行字数（自动）」只读行已删除，`ReaderSettings.autoLineCharsOf` 与相关参数一并移除。
  - `ReaderPage` 删除 `_maybeAutoReflow`/`_rebuildLines`/`_autoLineChars`，屏幕旋转、字号/字距/边距变化只重建 `LayoutSnapshot`（视觉行），语义行与语音对齐索引保持不变。
  - `LayoutSnapshot` 的 key 已包含画布宽度与字号等排版参数，宽度变化时只重算视觉行映射。
- 迁移：旧预设中的 `maxLineChars` 字段读入时忽略（`ReaderSettings.fromJson` 不读取该键），写回时不再输出；不抛异常，旧数据可直接打开（该键在 0.18–0.21 已为历史字段）。
- 历史说明：0.21.0 之前按「舞台宽度 + 字号 + 台本平均字宽」自动算每行字数并重建语义行；段落化后该机制不再适用，已整体删除。

## 9. 固定阅读带与视觉行（阶段 A，2026-11-09）

### 9.1 坐标模型

- **语义行**（`ScriptModel.lines`）继续用于语音对齐、断点、遥控行号与录制；2026-11-10 起语义行 = 段落（按空行切分），段内用 `anchorChar` 字符偏移定位；**视觉行**只用于渲染与滚动。
- `packages/core_reader_layout` 提供纯 Dart 模型：
  - `RowMeasurer`：宿主注入的文本测量接口；Flutter 侧 `_FlutterRowMeasurer` 用 `TextPainter.computeLineMetrics` + `getLineBoundary` 切分，保证视觉行与真实折行一致。
  - `LayoutSnapshot`：视觉行几何、语义行 ↔ 视觉行映射、`pitch = rowHeight + rowGap`、`targetForRow(row) = row × pitch`；`rowForChar(line, charOffset)` 把段内字符偏移映射到视觉行。
  - `ReadingBand`：固定阅读带；带中心 = 安全区顶部 + 安全区高度 × `readAheadRatio`（默认 0.34），并按上下最少行数夹取；带顶 `bandTop = bandCenter − rowHeight/2`。
  - `ReadingFollower`：一阶限速跟随；`tau` 由 `smoothness` 映射（4→108 ms，8→76 ms，12→44 ms），常态上限 1800 px/s、追赶上限 3000 px/s。
  - `BandEmphasis`：位置强调 = `clamp(1 − |行号 − 锚点行| / 0.9, 0, 1)`；关闭「经典高亮」时使用。

### 9.2 跟随规则

| 条件 | 行为 |
|---|---|
| 目标在前方（行号增大） | 立即提交目标，再叠加 60 ms 去抖只会增加切行延迟 |
| 目标回退/原地修正 | 保留 60 ms 去抖，避免口误把文字来回拽动 |
| 位移 ≤ 2.5 行 | 指数逼近，`tau` 由平滑度决定；240 ms 到 95%（单元测试实测） |
| 位移 > 2.5 行 | 启用追赶速度，跳过去抖 |
| 位移 > 8 行 | 直接落位，120 ms 淡入；不穿越中间内容 |
| 暂停/拖拽 | `freeze()` 停在当前位置；松手吸附到最近视觉行 |
| 手动滚动 | 按 `speed` 行/秒推进，位置直接改，目标跟随位置 |

### 9.3 渲染

- 正文 `Column` 顶部先放 `bandTop` 空白，随后每个视觉行固定 `rowHeight`、底部 `rowGap`；滚动变换为 `-position`，因此第 `i` 行走到 `i × pitch` 时行顶正好落在 `bandTop`。
- 阅读带是屏幕空间的静态覆盖层（`IgnorePointer`）：带背景 + 上下细线 + 左侧标记条；带上下用背景色渐变遮罩收拢注意力。
- 「经典高亮」开关只切换着色逻辑：开启时按行号身份（当前行全亮、下一行 0.72、其余压暗 + 行内标记条）；关闭时按位置强调连续插值，阅读带不移动。
- 镜像/分光镜按视口中心合成矩阵；垂直镜像的滚动目标为 `row × pitch + 2 × bandTop − H − prismDy × H`，保证行顶仍落在带顶。

### 9.4 缓存与性能

- 快照按「文本修订 + 画布宽 + 字号/行高/字重/字距 + textScaler + 对齐」生成 key；语音 partial 更新只改锚点与目标，不再逐行重建 `TextPainter`。
- 仍未做可视窗口裁剪：全部视觉行 Widget 仍参与构建；1000 行台本的帧耗时需真机实测。

### 9.5 排版迁移

- 新模型 `lineHeight` = **含行间距的总行距倍数**，默认 `1.55`；`textStyleHeight = lineHeight − 0.20`，`rowPadY = 0.05 × fontSize`，`rowGap = 0.10 × fontSize`，因此 `pitch ≈ lineHeight × fontSize`。
- 旧预设缺少 `typographyModel` 时按旧实际行距迁移：`h + 0.28 + max(0.12, h − 1) × 1.1`（默认 1.5 → 2.33），打开不变样；旧值超过新上限 2.5 时按 2.5 夹取。
- `layoutVersion` 语义不变（仍是段落行号坐标系的版本号），遥控端不需要改协议；`readAheadRatio` 字段复用为阅读带中心比例，旧值 0.35 仍可读。
- 2026-11-10 起 `layoutVersion` 只在排版参数（宽度/字号/字距等）变化时递增；语义行集合不再随宽度变化，因此重排不会改变 `anchorLine`，只会改变 `anchorRow`。
- 段落化后的跨端坐标约定见 §11。

## 10. 篇尾与 early arm（阶段 B，2026-11-09；重排部分 2026-11-10 更新）

### 10.1 early arm（提前跨行）

- 位置：`packages/core_alignment` 新增 `EarlyArmDetector`，由 `reader_page` 在逐行闸门未推进时调用；严格档自动关闭。
- 条件（同时满足）：
  1. 当前语义行已读比例 ≥ 0.55（按对齐命中的台本 token 位置计算）；
  2. 识别文本尾部与下一语义行前 2 个 token 逐个模糊等价（`Normalizer.fuzzy`）；
  3. 连续 2 次命中，或本次为 final 结果。
- 行为：把目标提前设为下一语义行（只前进 1 行），仍走 `ReadingFollower` 的一阶逼近，不会瞬移。
- 计数在开始/恢复/跳转/停止语音/重排/循环复位时清空，避免跨行或跨索引沿用旧命中。
- 与文档命中的差异：设计稿的「命中率 ≥ 档位阈值 − 0.10」在 2 token 下会退化为「2 个里命中 1 个」，容易被行尾虚词误触发；实现改为**前缀全部命中**（等价于阈值 ≥ 0.95），严格档关闭、宽松档仅放宽 `margin` 且不降低到允许错配。该差异记录在阶段 B 测试记录中。

### 10.2 篇尾完成态

- 判定：`_started && !_paused` 且锚点为末行；语音模式需 `ReadingFollower.atRest`，手动模式以到达滚动边界为准；连续静止 0.6 s 才置 `_finished`。
- 停止（默认）：`_handleFinished()` 置 `_finished = true`、暂停跟随、显示「已到篇尾」；手动模式额外在控制区显示同文案。
- 循环：同一判定后延时 1.2 s 调用 `_restartLoop()`，复位跟踪器/闸门/early arm，锚点回 0，`jumpToWithFade` 到第 0 视觉行并解除冻结；**不重建语音会话与录制会话**。
- 复位点：开始、恢复、手动/遥控跳行、停止语音、循环复位、重排都会取消 `_loopTimer` 并清零 `_endRestMs`；`finished` 时点播放/轻点页面按循环复位处理。
- 遥控/悬浮窗：它们读取 `playing = _started && !_paused`，篇尾暂停后自动变为「暂停」；循环复位后恢复「播放」。行号与 `layoutVersion` 语义不变。

### 10.3 段落化后的重排（2026-11-10 更新）

- 自动重排与 `_rebuildLines` 已整体删除：语义行不再随宽度变化，屏幕旋转、字号/字距/边距调整只重建 `LayoutSnapshot`，语音会话、录音分片与对齐索引都不受影响。
- 阶段 B 的 `restartWith` 热替换保留在 `VoiceFollowSession` 中，但阅读页不再因宽度变化调用；未来若引入「按语义重新切段」的导入策略，仍使用该入口。
- 验收口径：旋转/调字号后 `anchorLine` 不变，`anchorRow` 按新宽度重算；录音不中断，遥控/悬浮窗只收到新的视觉行坐标。

### 10.4 跨端坐标契约影响（2026-11-10）

- 语义行号即段落号，`lineCount` 为段落数；`layoutVersion` 在排版参数变化时递增，遥控端据此丢弃视觉行缓存。
- 遥控协议升至 v3：新增 `anchorOffset`、`anchorRow`、`rowProgress`、`lineUnit=paragraph`、`anchorRowText`；旧 v1/v2 上行消息照常接受，旧遥控端忽略新字段后按段落粒度展示，不越界。
- 悬浮窗 `init` 新增 `rows`/`anchorRow`/`anchorOffset`，旧浮窗回退 `lines`/`anchor`（段落粒度）；外接屏 `lines`/`anchor` 直接改为视觉行，字段不变。
- 录制时间轴升至 v2（采样含 `char`）；v1 文件在回放/导出前按 `mapLegacyAnchorToParagraphs` 迁移，SRT 用视觉行输出。

## 11. 功能栏隐藏与开发入口（2026-11-10）

### 11.1 功能栏手动隐藏

- 入口：底部功能栏「隐藏功能栏」按钮（`Icons.visibility_off`，Tooltip `readerHidePanel`）。
- 行为：顶部栏与底部栏一起淡出，阅读区恢复全屏；状态写入 `app_settings.reader_panel_hidden`（全局，跨台本与重启保持）。
- 唤出：隐藏后右侧出现常驻把手（`ValueKey('reader-panel-handle')`，`Icons.chevron_left`，Tooltip `readerShowPanel`），单击即恢复；把手点击区域固定、不随自动淡出消失，避免误触后永久找不到入口。
- 锁定态：把手隐藏，但锁定角标仍可点击解锁；解锁后把手恢复。语音跟随、录制、悬浮窗同步只依赖锚点与定时器，与面板可见性无关。
- 自动淡出：面板可见时仍按 3 s 无操作淡出（`_panelVisible=false`），但 `_panelHidden` 是用户意图，二者独立；轻点阅读区只会恢复自动淡出的面板，不会清除持久化的隐藏状态。
