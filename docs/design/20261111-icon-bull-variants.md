## 2. 三个变体

| 变体 | 一句话意图 | 几何做法 |
| --- | --- | --- |
| **V1 · 正面对称牛头** | 一张收窄的白脸、两只外翻上翘的角，角是唯一识别点。 | 圆角梯形脸（380→260 宽）+ 两条二次贝塞尔锥形角（根 124 → 尖 32） |
| **V2 · 负空间牛头** | 一块白色圆牌，牛头用底色挖出来，实体是留白。 | 直径 704 的白圆 + 用 0 蒙版挖出脸与角（同 V1 轮廓，缩至圆内） |
| **V3 · 角与声波** | 牛角就是扩散弧，一道锥形角带两段回声，播报与牛共用一个符号。 | 角身止于曲线 62% 处断开，后接 70–86%、92–100% 两段渐细回声；暖橙小点作「声源」 |

### 24 / 32 px 是否还认得出牛头（按实际像素渲染判读）

| 变体 | 32 px | 24 px | 16 px |
| --- | --- | --- | --- |
| V1 | **能**：两只角 + 脸块都在，角的外翻方向清楚 | **勉强**：只剩「两个上翘尖角 + 一个小方块」，要靠上下文补全 | 退化成一个 V 形 |
| V2 | **勉强**：白圆里的深色形状还能看出两个角，但「负空间」这层读法已经丢失，第一眼是「白牌 + 深色图案」 | **不能**：只剩白圆 + 深色折角 | 白圆 + 一个暗点 |
| V3 | **不能**：读作「扇形/V 形 + 小横块」，更像发声而不是牛 | 不能，只剩一个 V | 一个 V 形缺口 |

结论：**只有 V1 在 32 px 成立**；V2 的负空间只在 48 px 以上成立；V3 的角形要到 48 px 才稳定指认，32 px 靠「发声」这层语义兜底。若最终要兼顾 32 px，应选 V1。
另需注意：V1 与 V3 是同族兄弟，32 px 下几乎分不出差别，实际只能选一个。

## 3. 牛头与大皖品牌的关系

「皖」字与安徽传统纹样里都没有牛，**这里明确定位为纯吉祥物**：借牛的「稳、耐读、不走神」对应提词器陪读不断线，蓝色家族仍来自大皖新闻，牛本身不声称任何地域典故。

## 4. 色板与现有 M3 主题

- 底蓝与 R2 方向 C 完全一致（`#2654BA → #132F7A`），仍与 `TpTokens.seed = #4F5BD5` 同族但更深，**不进 `ColorScheme`**，不与 indigo/teal/amber/rose 四档强调色竞争。
- 橙色 `#F5A838` 只出现在 V3 的声源点上，占图标面积约 0.2%，不构成第二重心；去掉不影响识别。
- 落地时启动背景继续用现有 `splash_background = #4F5BD5` 即可，本组不引入新的深橙底。
