## 2. 拆解：能直接复用的参数

按 1024² 全像素统计与逐点采样得到：

| 项 | 实测 | 结论 |
| --- | --- | --- |
| 底色 | `#0EC8A8`（顶）→ `#1CCD88`（底），中心 `#0CC899` | 竖向渐变差极小，**视觉上等于平涂单色** |
| 图形 | 实心色块 | **实心，无描边、无线稿、无阴影、无纹理、无文字** |
| 主体 | 近白大团块（`#FFFFFF`，边缘带极浅薄荷 `#E0F8F3`） | 占全图 **35.0%**，四边全部出血 |
| 强调体 | 一个**斜置圆角方块**，自带青→春绿渐变 `#0DC8A6 → #3DCF82` | 占 **15.1%**，圆角 ≈ 边长 24%，从右下边缘出血 |
| 镂空 | 强调块内两个白色圆头胶囊，宽 ≈ 78/1024 | 同轴、不等距，**极小面积**，不承担语义 |
| 底色占比 | **49.9%** | 场 + 团块 + 强调体 = 100%，没有第三层 |
| 圆角 | iOS squircle，半径 ≈ 0.21 × 边长（`y=0` 处填充从 `x≈202` 开始） | 与本项目现用的 0.219 一致，落地时无需改 |
| 呼吸区 | 无 | 图形之间只有 40–70/1024 的切口，四边不留白 |
| 小尺寸 | 24 px 仍读出「青绿底 + 斜向白带 + 深一档的方块 + 两个点」；16 px 只剩「青绿底 + 斜白带」 | 识别只押 **一条大斜轴 + 两个高对比大色块**，不押细节 |
| 气质 | 工具 / 科技 | 几何硬边 + 有机外轮廓，无机、无拟人、无吉祥物 |

形式化成四条规则（本轮照此执行）：

- **A 场**：单一高饱和色，视觉上平涂。
- **B 主体**：一块近白实心团块，占比 ≥30%，至少两边出血。
- **C 强调**：一个近族色的强调体，占比 10–15%，至少一边出血。
- **D 克制**：零呼吸区、零描边、全圆端头；小尺寸只押一个对比结构。

## 3. 这套语言里借什么、不借什么

| 借 | 不借 |
| --- | --- |
| 单色场 + 近白巨块 + 一个强调体的**三层结构**（最值钱的部分） | **斜置方块**这个具体形状：它承载 Workbuddy 的「卡片 / 代理」语义，提词器没有对应物，强行斜置就只是装饰 |
| 全出血、无描边、无阴影 | 青→春绿**渐变**：24 px 下只会退化成噪点 |
| 极小镂空（两点、两段缝） | **有机手绘外轮廓**：提词器的语义是机械的（文本行、时间轴），用几何直边更贴 |
| 小尺寸只押一个对比结构的克制 | 把三件事塞进一张图（R4 的教训） |

斜轴这一条用另一种方式保留：D1 把整组文本行整体上倾 18°，斜轴由**构图**承担，而不是由某个斜置方块承担。

## 4. 色相决策

**不复用被作废的深蓝**（`#2A4CA8 → #122A70`）。本轮：

| 角色 | 色值 | 说明 |
| --- | --- | --- |
| 场（靛紫） | `#4840DE → #6858F3` | 饱和靛蓝-紫，比旧的深蓝亮两档，避免回到被作废的方案 |
| 强调体（青绿） | `#12CFA8` | 取自 Workbuddy 自己的场色，平涂 |
| 主体（白） | `#FFFFFF` | 不照搬它的薄荷调白，用纯白保对比 |

- 与现有主题：`TpTokens.seed = #4F5BD5`（靛蓝），图标场色是同族更亮的一档（色相约 240° vs 232°），**只作品牌资产，不进 `ColorScheme`**。
- 青绿与主题的 teal `#00695C` 同族但更亮，同样只作图标色，不参与 UI 强调色。
- **为什么把青绿降级为强调体**：青绿是 Workbuddy 的场色，直接拿来当场色就是撞脸；降为强调体后，既借到它的「AI 工具」气质，又和项目已有的靛蓝底连续。
- **为什么强调体取平涂**：Workbuddy 的渐变在 24 px 只会变成脏点，小尺寸只押对比，不押材质。

## 6. 24 / 32 / 48 px 实测判读

按实际像素渲染后放大观察，不含任何美化：

| 方向 | 24 px | 32 px | 48 px |
| --- | --- | --- | --- |
| D1 滚动行 | **认不出提词器**：只读出 3–4 条斜杠，像「文本 / 列表」 | **认不出提词器**，但「在滚动」成立（倾斜 + 长短差） | 滚动文本的意象清楚 |
| D2 视线 | **认得出是眼睛**（白带 + 一根竖条），**认不出提词器** | 眼睛明确，但「看 / 可见」是通用语汇，不专指提词 | 眼睛 + 竖瞳清楚，气质最独特 |
| D3 声波柱 | **认不出声波**：四根缝隙只剩约 1 px，读作「条纹 / 音量」 | 读得出「声音 / 波形」，不知是提词 | 声波清晰，但易被当成音乐或录音 |
| D4 小牛 | **认不出牛**：只剩一个带角的团块 | 牛头可辨 | 成立，但与工具气质相冲 |

**结论要直说**：三个方向在 **24 px 都读不出「提词器」**，只有 D2 在 24 px 能读出「眼睛」。这是 24 px 的物理限制，不是画法问题——语义由名字（大皖提词器）承担，图标只承担「一眼记住」的识别。

## 7. D4 与 Workbuddy 语言是否兼容

**不兼容。** 三条理由：

1. **拟物 vs 无机**：Workbuddy 的每一个形状都是无机几何；牛头是拟物，且天生带「角色」。
2. **轴向冲突**：它押的是「斜轴 + 满出血」；牛头必须居中对称才有正面感，斜轴不存在。
3. **笔法冲突**：它只用等宽圆头胶囊；牛角是锥形（书法感），同画面里出现两套笔法，缩到 24 px 就是一团。

所以小牛只能作为**独立吉祥物 / IP 资产**（启动页、空态插图、关于页），不进图标。
