> 参考对象：大皖新闻（新安晚报社）、大皖Plus（安徽日报报业集团）的 App Store 图标。

## 1. 参考图标的实际设计语言

两款图标均取自 App Store 官方页面（非用户自制图）：

| 项 | 大皖新闻 | 大皖Plus |
| --- | --- | --- |
| 底色 | 单色宝蓝，取样约 `#0F3A97`，几乎无渐变 | 暖橙渐变，顶部 `#FEB350` → 底部 `#A83A00` |
| 图形 | 白色毛笔书法「大皖」二字，占宽约 80%，左下略重 | 白色毛笔书法「大皖」偏左下；右上角一组细白同心弧线（贝壳/水纹状） |
| 文字 | 汉字即图形，无英文、无拼音 | 同上，另有细线纹样作角标 |
| 构图 | 单主体、满出血、无边框无投影 | 主体 + 一个角部装饰，形成对角平衡 |
| 小尺寸 | 书法笔画粗、重心稳，缩到 48 px 仍成立 | 细线角标在 48 px 以下消失，但主体字仍可读 |

**共同语言**：单一高饱和色场 + 纯白图形 + 满出血圆角方 + 无描边/无投影 + 一个视觉重心（可带一个角部母题）。
**色彩分工**：蓝色对应「大皖新闻」（权威、新闻），橙色对应「大皖Plus」（服务、生活），构成同一家族的双色体系。

### 借鉴与不照搬

| 借鉴 | 不照搬 |
| --- | --- |
| 单色高饱和底 + 纯白图形的高对比结构 | 不写书法汉字（本图标要求无文字，且小尺寸不可读） |
| 大皖蓝 `#0F3A97` 的色相区间与「新闻蓝」气质 | 不复制任何具体字形、笔画或贝壳纹样 |
| Plus 的暖橙渐变作为家族第二色 | 不使用双色拼接背景、不做渐变描边 |
| Plus「主体 + 角部线纹」的对角平衡 | 不保留细线装饰作为主体（小尺寸会消失） |
| 满出血背景 + 平台自行遮罩 | 不加入投影、内发光、纹理 |

## 2. 三个方向

所有母版为 1024×1024 全出血方形（无圆角），预览用圆角遮罩模拟平台效果；图形不含任何文字。

| 方向 | 一句话意图 | 几何 | 32 px 表现 |
| --- | --- | --- | --- |
| **A · 声波弧** | 一颗声源与三道外扩弧线，把「开口播报」压成一个信号符号。 | 圆点 + 3 道 ±50° 弧，线宽 84/1024，圆心偏左 | 点 + 两道弧可读（约 2.6 px 线宽），16 px 退化为斑点 |
| **B · 提词流光** | 两条抬升的光轨，表达台本滚动、视线跟随。 | 两条 45° 平行粗线，线宽 150/1024，长 628 / 436 | 两条斜轨清晰（约 4.7 px），16 px 退化为两点 |
| **C · 台词光标** | 两条台本行，一颗暖橙光标，标出读到哪一行。 | 两条圆角横条（500×80 / 336×80）+ 直径 160 橙色圆点 | 最稳：两条横线 + 光点在 32 px 仍可读，24 px 可辨 |

- **A** 把 Plus 的同心线纹转译为声波，语义最接近「播报/跟读」，但形态与系统 Wi-Fi/信号图标较近，需要靠圆点与弧的角度区分。
- **B** 唯一使用大皖橙底，家族识别最强，动态感最好；抽象度最高，不解释也能读成「向前/滚动」。
- **C** 最贴近提词器本体（台本行 + 阅读位置），小尺寸最稳；与当时在用的上一版图标语义连续，但已去掉声波条纹，更简洁。

## 3. 色板与现有 Material 3 主题的关系

现有主题：`TpTokens.seed = #4F5BD5`（靛蓝），`ColorScheme.fromSeed` 生成全部角色；强调色预设为 indigo / teal `#00695C` / amber `#9A6200` / rose `#B3365A`。

| 角色 | 色值 | 用途 | 与现有主题的关系 |
| --- | --- | --- | --- |
| 大皖蓝（A/C 底） | `#2A4CA8 → #122A70` | 图标底色 | 与 seed `#4F5BD5` 同属蓝紫家族，色相约 222° vs 232°，明度更低；**只用于图标**，不改 UI seed |
| 大皖橙（B 底） | `#F6AE54 → #D65818` | 图标底色 | 取自 Plus；与 UI 的 amber 预设 `#9A6200` 不同层：前者是图标品牌色，后者是控件强调色 |
| 暖橙光标（C 点缀） | `#F5A838` | 图标内唯一强调点 | 面积 <4%，不参与 UI 配色 |

结论与建议：

1. **不引入新主题色**。图标色是品牌资产，不进入 `ColorScheme`，避免与用户已选的强调色（尤其 amber）打架。
2. 图标蓝比 seed 更深、更「新闻」，两者并置时是「同一家族的不同明度」，不会显得两套品牌。
3. 若最终选 B（橙底），需要同步把 Android 12+ 启动背景从 `#4F5BD5` 改为 `#D65818` 附近的深橙，否则启动画面与图标会割裂；A/C 则可继续沿用现有靛蓝启动背景。**这属于落地阶段改动，本轮不做。**
4. 若后续希望图标色进入 UI，建议只在启动画面/关于页使用，不要替换 `TpTokens.seed`。
