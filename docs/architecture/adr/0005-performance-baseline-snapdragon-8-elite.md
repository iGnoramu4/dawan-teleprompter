# 0005. 性能基准定位为中高端 Android（骁龙 8 Elite / 12 GB）

- 状态：Accepted
- 日期：2026-11-06
- 决策人：TL（依用户要求）
- 关联：TESTING.md §6/§7/§8、ADR-0004、计划文档 §3.3/§14.4

## 背景

早期基线把「低端机可用」当作设计约束（例如 TESTING 曾写「4 GB RAM / 低端跟随 / 低端 ≥ 45 fps」）。实际使用场景是演讲、直播、课程录制等对设备有一定要求的工作场景，低端机并非目标用户。为避免为低端机压缩字形缓存、锁帧率或简化视觉，同时让性能验证有明确、可复现的基准，需要重新定义性能定位。

## 决策

Android 性能基准改为**中高端档**：骁龙 8 Elite 级 SoC + 12 GB RAM、Android 15/16、120 Hz 屏。低端机（4 GB、入门 SoC）只作启动/导入/阅读冒烟记录，**体验未保证，不作为门禁或设计约束**，也不为其做降级取舍。

同时核查现有实现是否存在低端专属限制，结论：**无**。

| 项 | 现状 | 处置 |
|---|---|---|
| 字形/图片缓存 | 未设置 `imageCache` 上限或用低分辨率字形 | 不动 |
| 帧率 | 未锁帧或降采样滚动 | 不动 |
| 特效 | 高亮/镜像/渐隐均为常规实现，无低端简化分支 | 不动 |
| ASR 模型 | `zipformer-zh-14M-int8`（常规精度/体积选择，非低端妥协） | 不动 |
| 阅读页帧采样 | `FrameTiming` 最多存 3600 帧，仅诊断用 | 保留（与机型无关） |

因此本轮**没有可放宽的降级项**，不需要额外的放宽前后对比实测；基线数值不变，仅把适用机型收窄到基准档。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 保持低端门禁 | 覆盖面广 | 限制视觉与性能设计，验证成本高 | 否决 |
| 中高端基准 + 低端冒烟 | 目标明确、可复现、设计自由 | 低端体验不承诺 | 采用 |
| 完全不做机型基线 | 最省事 | 性能退化无法判定 | 否决 |

## 影响

- 正面：性能验证只需盯一档机型；可放心使用完整字体、高刷滚动与现有视觉。
- 负面：低端机可能出现掉帧或内存偏高，需在兼容机冒烟记录中如实标注「未保证」。
- 不改变现有构建配置、模型与资源，无迁移成本。

## 验证方式

- 基准机型跑 profile/release：冷启动、跟随态帧率、CPU、PSS、耗电，写入 `docs/testing/records/<日期>-perf.md`。
- 低端/兼容机只记录启动、导入、阅读冒烟结果。
- 发布门禁按 TESTING §8 执行，低端结果不阻塞。
