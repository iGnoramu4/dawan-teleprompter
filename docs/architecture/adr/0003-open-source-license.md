# 0003. 采用 Apache-2.0 全量开源

- 状态：Accepted
- 日期：2026-11-06
- 决策人：TL
- 关联：计划文档 §15.4、§17 D3

## 背景

项目定位为**开源、免费、不商用**。需要选择一种能让第三方自由使用、修改、再分发与商用的许可，同时与上游生态（sherpa-onnx 等）兼容，并能随 App Store 分发。维护者不打算提供付费版本、商业授权或 SaaS，也不希望未来单方面改为闭源。

## 决策

- 代码采用 **Apache-2.0**；
- 全量开源（应用、核心算法、插件）；
- "不商用"**只写在 README/运营说明**，不写进许可条款；
- 贡献者协议采用 **DCO**，不设 CLA；
- 模型权重不纳入代码许可，单独 `MODEL_LICENSE.md`，不可再分发者改为用户本地导入；
- 依赖只允许白名单许可（Apache/MIT/BSD/ISC/Zlib/Unlicense）。

## 备选方案

| 方案 | 开源（OSI） | 专利授权 | 商用限制 | App Store 兼容 | 结论 |
|---|---|---|---|---|---|
| Apache-2.0 | 是 | 明确 | 无 | 兼容 | **采用** |
| MIT | 是 | 无明示 | 无 | 兼容 | 备选 |
| GPL-3.0 | 是 | 有 | 有（传染） | 与商店条款冲突 | 否决 |
| CC BY-NC 4.0 | **否** | 无 | 禁止商用 | — | 否决（source-available） |
| 自定义"禁止商用" | 否 | 无 | 禁止商用 | — | 否决 |

## 影响

正面：

- 真正的开源身份，第三方可自由使用、二次开发、商用；
- 专利授权降低贡献者与使用者风险；
- 与 sherpa-onnx 等上游一致，便于回馈社区；
- 无 CLA，贡献门槛低，符合"永久开源"预期。

负面（必须接受）：

- 他人（含竞争者）可合法商用本项目，维护者无法收费；
- 无 CLA 意味着未来不能单方面改为闭源/双许可；
- 需要持续承担 `NOTICE`、依赖许可、模型许可的合规工作（E16，2 人日）；
- 品牌与商标不受许可覆盖，需单独 `TRADEMARK.md`。

## 验证方式

- 发布前 `tool/license_scan` 通过，生成 `NOTICE`；
- 仓库根存在 `LICENSE`、`NOTICE`、`CONTRIBUTING.md`、`SECURITY.md`、`TRADEMARK.md`、`MODEL_LICENSE.md`；
- CI 校验所有贡献提交带 `Signed-off-by`；
- 文档明确"NC 协议不算 OSI 开源"的取舍（计划文档 §15.4.1）。
