# 权限清单与降级说明

> 状态：生效 ｜ 责任人：FE ｜ 复核：M1 结束
> 唯一事实来源：计划文档 §10.11。本文件供开发、审核与隐私页引用；任何清单变更必须同步两者。

## Android

| 权限 | 用途 | 申请时机 | 拒绝后的降级 |
|---|---|---|---|
| `RECORD_AUDIO` | 语音跟随、录制 | 首次点"开始跟随"或"开始录制" | 切匀速滚动；录制不可用并提示；可重试 |
| `POST_NOTIFICATIONS`（13+） | 悬浮窗与语音跟随的前台服务通知 | 首次开启悬浮提词/开始语音跟随时申请 | **已接入**：拒绝后服务仍运行，仅通知不可见；悬浮窗与跟随不受影响 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` | 悬浮窗前台服务（`OverlayService`，`specialUse`） | 安装期声明，随悬浮窗启动 | 关闭悬浮窗即停止服务 |
| `FOREGROUND_SERVICE_MICROPHONE` | 语音跟随的麦克风前台服务（`VoiceService`） | 安装期声明，麦克风授权且开始收音后启动 | **已接入**：服务启动失败时保留应用内收音；退到后台可能被系统暂停 |
| `SYSTEM_ALERT_WINDOW` | 对其他 App 悬浮提词 | 首次点「悬浮提词」弹说明后跳系统设置 | **已接入**：不做悬浮，Snackbar 提示并保留应用内提词；应用内浮层与分屏引导待后续 |
| `CAMERA` | 遥控端扫码读取配对二维码 | 首次点「扫码配对」时由插件申请 | **已接入**：拒绝/无相机时显示说明并降级为粘贴配对串，连接流程不阻断 |
| `INTERNET` | 局域网遥控、局域网互传 | 无法运行时申请；由网络总开关门控 | 开关关闭时不创建监听；开启后仅绑定局域网 |
| `ACCESS_NETWORK_STATE` | 连接状态提示 | 随网络开关 | 无状态提示，功能可用 |
| `WAKE_LOCK` | 阅读常亮、长时跟随 | 进入阅读页 | 息屏后中断，提示调系统息屏时间 |
| `VIBRATE` | 触感反馈 | 随设置项 | 无触感 |

技术说明：`INTERNET` 属于安装期权限，不能运行时申请。"按需"体现为**功能门控 + 文档逐条对应**，不宣称"无网络权限"；对外表述为"零云端、零账号，网络仅用于你主动开启的局域网功能"。

## macOS（TCC / 沙盒）

| 能力 | 声明 | 申请时机 | 拒绝后的降级 |
|---|---|---|---|
| 麦克风 | `NSMicrophoneUsageDescription`、`com.apple.security.device.audio-input` | 首次开始跟随/录制 | 切匀速滚动；录制不可用并提示；引导到系统设置 |
| 相机 | `NSCameraUsageDescription`、`com.apple.security.device.camera` | 首次点「扫码配对」 | 显示说明并降级为粘贴配对串 |
| 本地网络 | `com.apple.security.network.server/client` | 首次开启遥控 | 遥控不可用，其余不受影响 |
| 辅助功能 | `AXIsProcessTrustedWithOptions` | 首次设置全局热键 | 降级为应用内快捷键 |
| 屏幕录制（P2） | `NSScreenCaptureUsageDescription` | 首次开启系统内录 | 仅录麦克风 |

## Windows

| 能力 | 声明 | 申请时机 | 拒绝后的降级 |
|---|---|---|---|
| 麦克风 | 系统隐私开关 + 应用清单 | 首次开始跟随/录制 | 切匀速滚动；录制不可用并提示；提示开启 |
| 相机 | 不支持（插件无 Windows 实现） | — | 点击扫码提示不支持，保留粘贴配对串输入 |
| 防火墙（局域网监听） | 首次监听系统弹窗 | 首次开启遥控 | 仅本机可用；提示放行专用网络 |
| 全局热键 | 无需系统权限 | 设置时检测冲突 | 冲突则提示改键 |

## 通用规则

1. 每个权限都有"为什么 + 拒绝会怎样"的中文说明；
2. 除台本读写外，任何权限缺失都必须有可用降级路径；
3. 不在启动时批量申请；按功能触发、可随时撤回；
4. 麦克风/录音只在用户主动点击"开始"后申请；
5. 系统设置中被关闭后，回前台检测并提示，不崩溃；
6. 发布前跑"权限清单 vs 功能清单"对照（CI + 手工），作为门禁。
