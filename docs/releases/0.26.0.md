# 0.26.0（2026-11-10）

> 状态：内测 ｜ 平台：Android（APK） ｜ 签名：**Android Debug 证书（非正式签名）**
> 主题：更名「大皖提词器」+ 全新应用图标 + **包名变更**（不兼容变更，需卸载重装）

## 这个版本能做什么

- 应用显示名为「大皖提词器」（英文 Dawan Teleprompter）：启动器、通知权限弹窗、macOS 菜单与 Windows 窗口标题统一。
- 全新应用图标：靛蓝渐变底 + 白色「台本行 → 声波」简形符号，无文字；Android 自适应图标（前景/背景/monochrome）、Android 12+ 启动画面、Windows 多尺寸 `.ico`、macOS `.icns` 全部替换。
- 包名改为 `com.dawan.teleprompter`（Android `applicationId` / macOS bundle identifier 一致）。
- 功能与 0.25.0 相同：语音跟随为读音近似匹配（拼音音节级），同音字/近音字不再要求文字一致。

## 变更

### Added

- 应用图标与三端图标资源：`assets/branding/`（母版、Android 各密度、Windows `.ico`、macOS `.iconset`/`.icns`），生成脚本 `tool/generate_icons.py`。
- Android 12+ 启动画面主题（`values-v31` / `values-night-v31`）与旧版启动图 `launch_background`。
- 开源仓库内容：根 `README.md`、`BUILDING.md`、`.gitignore`、CI、Issue/PR 模板、第三方许可清单、包名变更说明。

### Changed

- 显示名改为「大皖提词器」：Android `android:label`、Windows 窗口标题与文件属性、macOS `CFBundleName`/`CFBundleDisplayName` 与菜单、应用内标题与遥控/互传文案（中英 ARB 同步）。
- 包名改为 `com.dawan.teleprompter`：Android `applicationId`/`namespace`（集中到 `android/gradle.properties` 的 `appApplicationId`）、Kotlin 包路径、`overlay_bridge` 与 `tool/eval_device` 附属包、macOS `PRODUCT_BUNDLE_IDENTIFIER`（含 RunnerTests）。

## 升级注意事项（重要）

- **本版与旧版不是同一个应用**：无法覆盖升级，必须先在设备上卸载旧包 `com.tp.prompter.teleprompter`，再安装本版。
- 旧包数据（台本、设置、录音、日志、已解包模型）**不迁移**，卸载后不再可用。详见 [包名变更说明](../help/package-rename.md)。
- 数据库名、应用私有目录名与 SharedPreferences 键名未改，仅用于新安装自身的一致性，不用于跨包读取旧数据。
- 与旧包可同时存在于设备（包名不同）；确认不再需要旧版后再卸载旧包。

## 已知问题 / 待验证

- 桌面端（macOS/Windows）本轮未打包，图标与产品名仅做了静态校验（`plutil`/XML/ICO 尺寸/icns 解析）；实际安装包外观待后续构建确认。
- 语音跟随本轮只做启动验证：ASR 引擎加载、麦克风采集、静音时正确显示「未检测到语音」，未跑 10 段评测；功能代码与 0.25.0 一致，评测结论见 `docs/testing/records/20261110-pinyin-matching.md`。
- 本轮沿用 Debug 签名，不能作为正式发布签名使用。
