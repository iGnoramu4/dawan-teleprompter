# 0.17.0 发布说明（M2 内测）

> 版本：`0.17.0+2020` ｜ 日期：2026-11-06 ｜ 平台：Android ｜ 状态：内测
> 渠道：GitHub Release（仅 APK，**未使用正式签名**）｜ 目的：汇总 M2 的遥控、外接显示、扫码配对与录制/复盘能力，供内测用户与验收使用。

## 1. 这个版本能做什么

- **局域网遥控**：手机/另一台设备打开「遥控端」，粘贴配对串或扫码连接，控制当前阅读页的播放、上一行/下一行、速度、镜像与锁定；
- **外接显示**：Android 连接 HDMI/DP 副屏后，从阅读页一键输出纯稿件（黑底白字、当前行高亮、5 行窗口、可镜像）；
- **扫码配对**：遥控端用相机扫描主控端二维码自动连接；相机不可用/权限拒绝时退回粘贴配对串；
- **录制与复盘**：阅读页录制音频并每 100 ms 记录当前行号；录制历史里可回放并联动稿件，支持播放/暂停、拖动、0.5×–2×；
- **导出**：录制 WAV、`timeline.json` 与 `captions.srt`，通过系统「另存为」选择目标位置。

## 2. 升级注意事项

- **非正式签名**：本版本仅用于内测，APK 使用 Flutter 模板默认的 debug 签名（`signingConfigs.debug`），**不是正式发布签名**；安装时 Android 可能要求「允许安装未知来源应用」，部分安全软件会提示风险。请只从发布页下载，并核对 SHA256；
- 本版本不发布 macOS/Windows 安装包，也不进入应用商店；
- 数据库 `schemaVersion` 从 1 升到 2，新增 `recordings` 表；旧数据自动原地迁移，无需手动操作；
- 首次使用录制会请求麦克风权限；首次扫码会请求相机权限；拒绝后有降级路径，不阻断其他功能；
- 录制音频保存在应用私有目录，卸载应用会删除；需要保留请在「录制历史」中导出；
- Windows 暂不支持复盘播放（无官方播放器实现），会出现明确提示；录制与导出不受影响。
