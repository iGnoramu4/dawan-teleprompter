# 0.27.0（2026-11-11）

> 状态：**已出 release（图标定稿）** ｜ 平台：Android（APK） ｜ 版本口径：`version: 0.27.0+2030`
> 主题：让跟随更早、更稳；阅读页去掉高亮与遮罩；应用图标定稿

## 这个版本能做什么

- 语音匹配只按读音判定（拼音音节），同音、近音、漏读一个音节都不再要求文字一致。
- 放行单位从「逐字命中」改成「整行读音覆盖度」：一行读到足够比例就滚到下一行，行内个别字漏读/错读/跳词不卡住跟随。
- 连续朗读时自动放宽闸门，长时间没声音或置信持续偏低自动收回；任何档位、任何路径最多一次跳 3 行。
- 换行比语音略早：把采集、解码、渲染的延迟前馈到滚动目标（默认开，可关，可观测）。
- 阅读页只保留正文下方一条细线指示当前行；正文一种颜色，没有行内底色、左侧标记条和底部暗晕。

## 变更

### Changed

- 匹配只有读音口径：删除「按读音近似匹配」开关与文字逐字分支；模糊音新增 `f/h`、`r/l`、`uang/uan`、`iang/ian`、`ing/in`、`eng/en`、`ang/an`、`iu/ou`；音节级编辑距离 ≤1（声母相同）。
- 整行读音覆盖度放行：分母为该语义行的有效音节，分档阈值 0.9/0.8/0.72/0.65，叠加「最远命中 ≥60%」与行内单调前进；对齐出现下一行读音且覆盖达标即放行。
- 连续朗读自适应：进入（5 次合格更新 + 8 s 内推进 ≥3 行 + 间隔 ≤2.5 s）与退出（>2.5 s 无输出 / 连续 3 次低置信）明确；`confirm/weak` 各 -0.08、`weakHits` 2→1。
- 端到端延迟补偿：40 ms 分片 + 实测 `decodeMs` + 16.7 ms 帧，EMA 后按语速折算 0–0.8 行前馈；每 5 s 写 `voice/latency_compensation`。
- 阅读页视觉：移除行内底色、左侧标记条、下一行半亮、非当前行压暗、透明度渐变、底部/顶部暗晕；当前行仅留 1.5 px 下划线。
- 设置项移除「当前行高亮」「经典高亮」「下一行半亮」「按读音近似匹配」，新增「跟随延迟补偿」。

### Added

- 跳读硬上限不变量 `maxAutoLeapLines = 3`（闸门 / 跟踪器 / 提前跨行三处 clamp）与 5 个防回退测试。

## 升级注意事项

- 旧预设不必手改：`phoneticMatch`、`matchMode`、`highlightEnabled`、`showNextLine`、`classicHighlight` 读入时忽略，保存时不再写出；不会因为缺键崩溃。
- 老用户升级后「按读音近似匹配」开关消失，行为等同于此前的默认开启态。
- 视觉变化较大（无高亮、无压暗、无底部渐隐），首次进入可能觉得「少了强调」，当前行靠下划线定位。

## 已知问题 / 待验证

- 行级覆盖度的收益在现有 10 段评测集（照稿朗读）上体现不出来：与旧闸门数字完全一致，差异只在「行内漏读导致跨行证据置信 0.35–0.55」时出现，需真人漏读场景复测。
- 行级覆盖与连续朗读放宽态同时生效的叠加行为，评测集未触发过放宽态，未实测。
- 1.5 px 下划线仅出 44 px 字号截图；24/160 px、四组镜像、分屏未逐一截图。
- 30 分钟静音为数字静音，真实环境底噪长跑未做。
