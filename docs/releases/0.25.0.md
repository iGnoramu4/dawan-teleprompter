# 0.25.0（2026-11-10）

> 状态：内测 ｜ 平台：Android（APK） ｜ 签名：**Android Debug 证书（非正式签名）**
> 主题：语音跟随改为**读音近似匹配**（拼音音节级），同音字/近音字不再要求文字一致

## 这个版本能做什么

- 真人朗读与台本**读音一致**即可跟随：同音字（重点/终点）、近音字（zh/z、n/l、-in/-ing、-an/-ang、-en/-eng）不再判为错读，减少「明明读了却不走」的卡顿。
- 多音字按上下文取主读音，同时保留全部读音做兜底：`银行` 的「行」读 hang 或 xing 都能命中；`重要` 的「重」读 zhong 可命中。
- 数字按中文口播读法对齐：台本写 `12.5%`，识别成「百分之十二点五」仍满置信命中。
- 英文术语整体匹配：`SDK`、`Wi-Fi`、`sherpa-onnx` 不被逐字母拆散；识别流拆成 `S D K` / `WII FI` 时先合并再比较。
- 设置页可一键切回**文字逐字匹配**（「匹配档位」下方的「按读音近似匹配」开关，默认开启）；切换在跟读中生效，不打断麦克风。
- 阅读位置仍按字符偏移回填视觉行与段内字符，界面推进仍是连续的；匹配决策只来自音节命中。

## 口径说明（与旧版的差异）

| 项 | 0.24.0（字符口径） | 0.25.0（音节口径） |
| --- | --- | --- |
| 对齐单位 | 中文逐字、英文整词，比较无声调拼音模糊类 | 中文逐字 = 1 音节；英文整词 = 1 token；比较候选读音集合 |
| 多音字 | 只取第一读音 | 保留全部读音求交 + 词语表上下文主读音 |
| 声调 | 不参与 | 只作 0.1 加分项，不是硬条件 |
| 替换/漏读/多读代价 | 1.0 / 1.2 / 1.5 | 1.0 / 1.0 / 1.0（每音节 1 个错误） |
| `span` | 首命中到末尾的 token 数（字符口径） | 首命中到末尾的**音节**数 |
| 置信度 | `1 - spanError/(span*1.2)` | `1 - spanError/span`，即命中区间音节一致率 |
| 闸门阈值 | confirm 0.55 / weak 0.35 | 不变（10 段评测复核：无需调整） |

## 变更

### Added

- 读音近似匹配（默认）与文字匹配回退开关。
- 多音字多读音、数字口播、英文术语合并、分词边界无关的回归测试。

### Changed

- `Normalizer` 支持 `MatchMode.phonetic` / `MatchMode.literal`；台本索引 `lineKeys` 收录全部候选读音。
- 预筛、DP、early arm 统一用 `NormToken.matches`（候选集合求交）。
- `AlignEngine` 按音节重算代价与置信度；声调不同 +0.1。

### Fixed

- 同音/近音导致「已读但不推进」：10 段评测命中率 87.2% → 100%（跨环境对照，见下）。

## 升级注意事项

- 可直接覆盖安装（`adb install -r` 验证通过），本地数据与旧台本保留；旧设置预设缺省按**读音匹配**加载。
- 说明：以上覆盖安装仅适用于 0.25.0 与 0.24.0（同为旧包名 `com.tp.prompter.teleprompter`）。包名改为 `com.dawan.teleprompter` 之后的构建是**全新安装**，不能覆盖升级，旧包数据不迁移，见 [包名变更说明](../help/package-rename.md)。
- 需要严格字面匹配的用户可在设置中关闭「按读音近似匹配」，行为回到 0.24.0 的逐字比较（多音字仍保留候选读音，但不再做拼音模糊等价）。
- 读音匹配会扩大「可接受读音」的范围，极端情况下可能让口误更容易被当成命中；本版以 10 段评测与静音长跑守住误触发（见测试记录），真人环境若发现抢行可先收紧匹配档位或关闭读音匹配。

## 已知问题 / 待真人验证

- 同音字大量替换、方言口音（如平翘舌全混）在真实麦克风下的收益，需真人朗读确认；评测集为合成/录制音频，不等同真人现场。
- 英文术语的识别质量取决于 ASR 模型；`SDK` 被识别成 `X D K` 等非术语表写法时仍按词对齐，可能降置信（不会回跳）。
- 30 分钟静音长跑与真机 10 段结果见 `docs/testing/records/20261110-pinyin-matching.md`。
