# 0.24.0（2026-11-10）

> 状态：内测 ｜ 平台：Android（APK） ｜ 签名：**Android Debug 证书（非正式签名）**
> 主题：真机反馈缺陷修复（换行丢失 / 跟随卡住 / 跳读与回跳）+ 提词页去掉分段

## 这个版本能做什么

- 提词页段落内的换行不再丢字：视觉行先按硬换行切段再折行，36/44/52 px 字号与横竖屏均完整显示。
- 语音跟随卡住时不再一律提示「未收音」：按「音频分片 / 解码心跳 / 文本更新」三路状态区分原因，角标分别提示「麦克风中断，正在重连…」「识别引擎无响应」「已收音，未匹配稿件」，并写入诊断日志（`voice/health`、`gate_stalled`）。
- 跳读与回退收敛：越级推进需置信门槛、预筛前看 3 行、回退候选默认不采纳；锚点默认单调不后退（手动跳行与显式重新定位除外）。
- 提词页按整篇连续文本渲染，不再有「分段」概念与分段跳转；旧台本的分段、标记与断点自动映射到连续文本。

## 变更

### Fixed

- 段落内换行后文字不显示（视觉行切分）。
- 跟随卡住时文案与实际原因不符（新增采集/引擎/闸门三类判定）。
- 跳读过多（`maxLeap` 加置信门槛、`> line+5` 候选加 `acceptFloor`、前看 8→3 行且不再回看）。
- 突然回到前面（回退候选一律 `heldBack`、阅读页单调守卫、平滑只向前、`isFinal` 不再段内后退）。

### Removed

- 提词页分段跳转（「跳转到段落」对话框）与分段进度展示；进度改为只读连续行号。

## 升级注意事项

- 可直接覆盖安装（`adb install -r` 亦验证通过），本地数据保留。
- 旧台本无需转换：`rawText` 优先、为空时按 `sections` 拼接；旧标记按分段 `ord` 映射到连续文本语义行，旧断点按分段顺序折算行号。
- 遥控端旧协议仍被接受：`jump` 可继续传 `sectionId`，新端优先使用 `line`。
- 悬浮窗/外接屏收到的是视觉行（`lines`），旧接收端自动回退旧字段。

## 已知问题 / 待真人验证

- 「断流自愈」（`captureStalled` 判定 + 每 3 s 自动重开采集）仅单测覆盖，**未在真机验证**，不计入已修复项。
- 跳读/回跳的真人朗读效果、慢读停顿与角标语义需真人自测，清单见 `docs/testing/records/20261110-p1p4-device-fixes.md`。
