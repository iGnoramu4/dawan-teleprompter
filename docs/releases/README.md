# 发布说明索引

> 状态：生效 ｜ 责任人：TL ｜ 更新：2026-11-12
> 命名：`<version>.md`（与 `apps/app/pubspec.yaml` 的 `version` 主次号一致；构建号不写进文件名）。

## 规则

- 每个对外发布版本一份，发布后归档、不再改写（勘误以追加「勘误」小节的方式记录）；
- 内容按 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 分类：Added / Changed / Fixed / Removed / Security；
- 用户视角优先：先写「这个版本能做什么」，再写限制与已知问题；
- 必须包含：版本号、发布日期、平台、升级注意事项、已知问题、校验信息（发布时回填 SHA256）；
- 发布检查按 [release-checklist.md](./release-checklist.md) 执行，构建与签名步骤见 [release-runbook.md](../ops/release-runbook.md)。
