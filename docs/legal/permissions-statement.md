# 权限说明（用户版）

> 状态：生效 ｜ 责任人：FE ｜ 更新：2026-11-06
> 技术清单与三端差异见 [permissions.md](../permissions.md)；隐私处理见 [隐私政策](./privacy.md)。

应用只在功能触发时申请权限，不在启动时批量索取；每个权限都有拒绝后的降级路径。

## Android

| 权限 | 为什么需要 | 拒绝后 |
|---|---|---|
| 麦克风 | 语音跟随、录制 | 匀速滚动可用；录制提示不可用 |
| 相机 | 扫描遥控配对二维码 | 改为粘贴配对串 |
| 通知（13+） | 悬浮窗/语音跟随的前台服务提示 | 服务仍运行，仅通知不可见 |
| 显示在其他应用上层 | 在其他 App 上悬浮提词 | 保留应用内提词 |
| 网络 / 网络状态 | 你主动开启的局域网遥控与互传 | 相关功能不可用 |
| 屏幕常亮 / 震动 | 阅读不息屏、按键触感 | 按系统息屏或无触感 |

## macOS

| 能力 | 为什么需要 | 拒绝后 |
|---|---|---|
| 麦克风 | 语音跟随、录制 | 匀速滚动；录制不可用 |
| 相机 | 扫描配对二维码 | 改为粘贴配对串 |
| 本地网络 | 局域网遥控/互传 | 相关功能不可用 |
| 辅助功能 | 全局热键（如启用） | 降级为应用内快捷键 |

## Windows

| 能力 | 为什么需要 | 拒绝后 |
|---|---|---|
| 麦克风 | 语音跟随、录制 | 匀速滚动；录制不可用 |
| 防火墙放行 | 局域网遥控监听 | 仅本机可用并提示 |
| 相机 | 不支持 | 保留粘贴配对串 |

## 说明

- 麦克风与相机只在点击「开始跟随/录制」「扫码配对」时申请；
- 系统设置中关闭权限后，回到应用会提示，不会崩溃；
- 音频与相机画面仅在本机处理，不上传；
- 可随时在系统设置中撤回权限，撤回后应用内提词仍可用。
