# 隐私政策

> 状态：生效 ｜ 责任人：TL ｜ 更新：2026-11-06 ｜ 生效日期：2026-11-06
> 适用：大皖提词器（Dawan Teleprompter）Android / macOS / Windows 客户端。

## 1. 我们收集什么

**默认不收集任何个人数据。** 应用零云端、零账号，台本、设置、录制音频、数据库均保存在你的设备本地。

| 数据 | 位置 | 用途 | 是否离开设备 |
|---|---|---|---|
| 台本与编辑内容 | 应用私有目录 + 本地数据库 | 提词与备份 | 否（除非你主动导出/互传） |
| 阅读设置/预设 | 本地数据库 | 恢复你的排版与跟随参数 | 否 |
| 录制音频与时间轴 | 应用私有目录 `recordings/` | 复盘与导出 | 否（除非你主动导出） |
| 运行日志 | 应用私有目录 `logs/` | 本地排障 | 否（除非你主动导出诊断包） |
| 诊断包 | 你选择的位置 | 反馈问题时提供给支持人员 | 仅在你主动导出并发送时 |

## 2. 权限与用途

| 权限/能力 | 用途 | 拒绝后 |
|---|---|---|
| 麦克风 | 语音跟随、录制 | 匀速滚动可用；录制不可用并提示 |
| 相机 | 遥控端扫描配对二维码 | 降级为粘贴配对串 |
| 通知（Android 13+） | 悬浮窗/语音跟随的前台服务通知 | 服务仍运行，仅通知不可见 |
| 显示在其他应用上层 | 系统级悬浮提词 | 保留应用内提词 |
| 本地网络 | 你主动开启的局域网遥控/互传 | 相关功能不可用 |
| 屏幕常亮 | 阅读时不息屏 | 按系统息屏时间 |

完整清单与三端差异见 [permissions.md](../permissions.md)。

## 3. 第三方组件

| 组件 | 作用 | 数据处理 |
|---|---|---|
| `sherpa-onnx` / 本地 ASR 模型 | 语音识别 | 音频在本机处理，不上传 |
| `mobile_scanner` + Android MLKit | 二维码解码 | 相机帧在本机处理，不上传 |
| `just_audio` / `record` | 音频播放与采集 | 仅本地文件与麦克风流 |
| `pdfrx` / `pdfium` | PDF 文本提取 | 仅本地文件 |

依赖与许可清单见 [NOTICE](../../NOTICE) 与 [DEPENDENCY_POLICY](../process/DEPENDENCY_POLICY.md)。

## 4. 网络行为

- 应用不主动连接任何服务器；
- 局域网遥控/互传仅在你手动开启后监听本机地址，关闭页面即停止；
- 遥控使用随机 token 鉴权；连续失败会临时封禁来源地址；
- 无广告、无统计 SDK、无崩溃上报 SDK。

## 5. 数据保留与删除

- 数据保留在你的设备上，直到你删除台本/录制或在系统中清除应用数据；
- 删除台本（永久删除）会级联删除关联录制与音频文件；
- 卸载应用会删除应用私有目录内的全部数据；
- 导出的文件由你自行管理。

## 6. 儿童隐私

应用不面向儿童设计，不主动收集任何年龄信息；如监护人发现问题，请联系我们。

## 7. 你的权利

你可以在应用内查看、导出、删除数据，也可以卸载应用清除全部本地数据。需要协助时通过下方联系方式沟通。

## 8. 变更
