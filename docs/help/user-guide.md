# 用户手册

> 状态：生效 ｜ 责任人：FE/UI ｜ 更新：2026-11-09 ｜ 适用：`0.18.0+2021`
> 目的：让新用户在不看开发文档的情况下完成导入、提词、遥控、录制与导出。

## 1. 安装与首次启动

- Android：安装 APK/AAB 对应产物；首次启动按提示授权通知（可拒绝，不影响提词）。
- macOS：打开 DMG 拖入「应用程序」；首次使用麦克风/相机会出现系统授权弹窗。
- Windows：运行安装包；首次开启遥控时防火墙可能弹窗，选择「专用网络」。
- 应用无需账号、无需联网即可使用；网络仅用于你主动开启的局域网遥控/互传。

## 2. 导入台本

支持 `.txt`、`.md`、`.tps`（本应用台本包）、`.docx`、`.pdf`（仅文本层）。

1. 首页点「导入」或台本卡片菜单；
2. 选择文件（Android 文件选择器中如看不到 `.tps`，改为「所有文件」）；
3. 预览并确认导入；重复导入会生成新台本，不会覆盖原稿。

扫描版 PDF 无文本层，会提示不支持；请先用 OCR 转换或改用 `.docx`。

## 3. 阅读与提词

- 打开台本后停在起始态，**轻点屏幕**或点「播放」才开始滚动；
- 控制栏：播放/暂停、上一行/下一行、速度、设置、麦克风、锁定；
- 设置面板可调字号、行距、边距、字距、居中、高亮、镜像；正文按空行分段、段内连续排布，只在段落之间换行，段内按屏幕宽度自然折行；旋转屏幕或改字号后只重排视觉行，阅读位置与断点保持不变；
- 功能栏可点「隐藏功能栏」收起，右侧把手可随时唤出；隐藏状态会跨台本与重启保持，不影响语音跟随、录制与悬浮窗；
- 开发构建会显示「回放测试音频（仅开发构建）」，正式版不显示；
- 镜像用于提词器分光镜；「锁定」后屏蔽手势，避免误触；
- 屏幕常亮在阅读页自动开启，退出后恢复系统设置。

## 4. 语音跟随

1. 点麦克风按钮，首次会请求麦克风权限；
2. 正常说话，当前行随识别结果逐行推进；
3. 顶部角标显示引擎状态（加载中/收音中/静默/低置信/暂停）；
4. 识别不理想时可在设置里关闭语音跟随，回到匀速滚动。
5. 设置面板「语音匹配宽松度」可选严格 / 标准 / 宽松：严格更不易抢行，宽松更容易跟进但可能被近似口播带偏；面板会直接显示当前档位的实际阈值（强命中、弱命中与 final 加成）。

拒绝麦克风权限时，跟随不可用但匀速滚动仍可正常使用。

## 5. 局域网遥控

1. 阅读页控制栏点「局域网遥控」；
2. 主控端显示二维码与配对串；
3. 另一台设备打开「遥控端」，扫码或粘贴配对串连接；
4. 遥控端可播放/暂停、上一行/下一行、调速、镜像、锁定、断开。

- 主控端退出阅读页即停止服务；
- 配对串包含一次性 token，请勿公开分享；
- 连接失败会自动重连 3 次，仍失败可手动重连。

## 6. 扫码配对

- 遥控端点「扫码配对」，对准主控端二维码；
- 相机权限被拒绝、无相机或 Windows 平台时，页面会说明原因并保留「粘贴配对串」入口；
- 扫到非配对二维码会提示，可继续扫描。

## 7. 外接显示（Android）

1. 用 HDMI/DP 连接副屏；
2. 阅读页点「外接显示」；多屏时选择目标屏；
3. 副屏显示 5 行纯稿件，当前行高亮，跟随阅读页字号与镜像；
4. 拔出副屏会自动停止；再次使用需重新点击。

无线投屏通常为系统镜像，不会出现在可选副屏列表。

## 8. 录制、复盘与导出

- **录制**：点红色录制按钮；首次请求麦克风权限。录制中显示计时与提示；
- **复用麦克风**：语音跟随已开启时，录制复用同一条采集流，不重复占用麦克风；
- **停止**：再点一次保存；取消则删除半成品；
- **历史**：控制栏「历史」查看 recordings；
- **复盘**：选一条录制播放，稿件按时间轴联动；支持播放/暂停、拖动、0.5×/1×/1.5×/2×；
- **导出**：导出 `.wav`、`.timeline.json`、`.captions.srt`，通过系统「另存为」选择位置；
- Windows 暂不支持复盘播放，会提示；录制与导出仍可用。

## 9. 悬浮提词（Android）

- 阅读页点「悬浮提词」，按说明授权「显示在其他应用上层」；
- 浮窗可拖动、关闭、切换开始/暂停与行号；
- 权限拒绝时保留应用内提词，不影响使用。

## 10. 备份与迁移

- 设置页可「立即备份」，自动备份保留最近 7 份；
- 支持导出/导入整包 `.tps`，以及局域网互传（浏览器下载/上传）；
- 换机前建议导出整包并保存到本机之外。

## 11. 获取帮助

- 设置页 →「诊断」→「导出诊断包」，把文件发给支持人员；
- 常见问题见 [FAQ](./faq.md)；安全漏洞请按 [SECURITY.md](../../SECURITY.md) 私下报告。
